# Máquina de Edição

Sistema de edição de vídeo automatizada, operado pelo Claude.

- `setup.sh`: instala dependências e modelos (rodar no início de cada sessão).
- `src/`: modelos visuais em Remotion (títulos, legendas, painéis).
- `entrada/` e `saida/`: vídeos brutos e editados (não vão para o Git).
